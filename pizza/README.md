# Пиццерия — сайт + админка

- `index.html` — сайт для клиентов: меню, корзина, заказ в WhatsApp.
- `admin.html` — панель владельца: позиции, цены, описания, фото, категории, настройки.
- `menu.json` — всё меню (админка сама сохраняет его сюда через GitHub API).
- `img/` — фото, загруженные из админки.

Вход в админку — ключ GitHub (fine-grained token, только репозиторий `raf`, Contents: Read and write).
